# Pasta UI Pro block reference

Every item below installs with `pnpm dlx shadcn@latest add @pastaui-pro/<slug>`. Blocks land in `components/blocks/<slug>.tsx` and components in `components/ui/<slug>.tsx`; import them from `@/components/blocks/<slug>` or `@/components/ui/<slug>`. Heading links open the category page, which shows a preview of every variant.

This is a snapshot. The live list, with descriptions, is https://pro.pastaui.com/llms.txt. If a slug here is missing from the registry, trust the live list.

Variants are listed newest first. Pick by character, not by number.
